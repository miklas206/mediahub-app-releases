# Plex GPU Transcoder

Installer Plex fra MediaHubs App Store. Åbn derefter den installerede Plex-app, og find **Plex-udvidelser → Plex GPU Transcoder**. Udvidelsen kræver et kompatibelt NVIDIA-kort, som er klargjort på Plex-værten. Plex kan også bruges alene.

Afslut igangværende afspilninger, og vælg **Installer eller opdater Plex GPU Transcoder**. Under **Vis transkoderstatus** kan du se forbindelsen og den aktuelle GPU-aktivitet. Senere opdateringer foretages samme sted. Den gemte bufferindstilling følger med. [Vejledning til installation direkte på Plex-værten](plex-gpu-transcoder.md)
